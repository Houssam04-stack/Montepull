# MVP-0 — Règles de validation

## Articles

`ART_CODE_REQUIRED`, `ART_CODE_UNIQUE`, `ART_TYPE_REQUIRED`, `ART_UNIT_REQUIRED`, `ART_FAMILY_MATCH`, `ART_INACTIVE`.

## Nomenclatures

`BOM_PARENT_UNKNOWN`, `BOM_COMP_UNKNOWN`, `BOM_QTY_POSITIVE`, `BOM_UNIT_REQUIRED`, `BOM_SCRAP_RANGE`, `BOM_DUP_LINE`, `BOM_CYCLE`, `BOM_OP_LINK_MISSING`.

## Gammes

`RTG_ARTICLE_UNKNOWN`, `RTG_NO_OP`, `RTG_SEQ_DUP`, `RTG_OP_CYCLE`, `RTG_CENTER_UNKNOWN`, `RTG_CYCLE_NEGATIVE`, `RTG_CYCLE_PLAUSIBILITY`, `RTG_SETUP_NEGATIVE`, `RTG_SETUP_MISSING`.

## Calendriers

`CAL_OVERLAP`, `CAL_RANGE`, `CAL_TRS_RANGE` (convention demo `[0;1]` — TO_CONFIRM).

## Sévérités

BLOCKING empêche le backtest sans by-pass ; WARNING dégrade le score ; INFORMATION informative.
