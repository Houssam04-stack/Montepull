# MVP-0 — Périmètre

Source de vérité produit : `Dossier_APS_conception.docx`.

## Objectif

Répondre : *Les données réelles d’une famille sont-elles assez fiables pour construire le moteur APS ?*

## Inclus

- Campagne mono-famille
- Imports versionnés + rapport
- Validation Articles / BOM / Gammes / Calendriers
- Anomalies BLOCKING / WARNING / INFORMATION
- By-pass tracé
- Indices fiabilité intrant + résultat
- Backtest sans solveur
- Gate GO / GO_WITH_RESERVATIONS / NO_GO / INSUFFICIENT_DATA
- Rapport 1 page

## Exclu

Solveur, ordonnancement, Gantt, CTP, optimisation, M2, M6, IA décisionnelle.
