# MVP-0 — Guide démo

1. Lancer l’app Web.
2. Ouvrir `/mvp0`.
3. **Chemin anomalies (SIMULATED)** : cocher SIMULATED, famille `PULL`, **Parcours demo bout-en-bout** → Gate = `INSUFFICIENT_DATA`.
4. **Chemin GO (REAL)** : décocher SIMULATED → Créer → sur le parcours : **Import seed REAL propre** → Validation → (pas de by-pass si propre) → Score → Backtest → Avis planificateur approuvé → Gate → Rapport.
5. **Assistant CSV** : `/mvp0/imports` — type, fichier, preview/mapping, import versionné, rapport de rejets.
6. Imprimer le rapport (Ctrl+P sur l’iframe).

Les menus APS restent sous **Prototype / Expérimental**.
